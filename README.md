# Schedulr

A social calendar app that blends personal scheduling with authentic, event-based sharing. Built with **SwiftUI**, **UIKit**, and **Firebase**.

---

## Overview
Schedulr puts calendar events at the center of social interaction. Users can only post from events on their calendar, encouraging genuine, experience-driven content while keeping scheduling collaborative and simple.

---

## Features
- **Smart Calendar:** Create and organize events with time, location, notes, and custom colors  
- **Social Scheduling:** Merge calendars with friends to check availability without sharing private details  
- **Event-Based Posts:** Share posts tied to real events with automatic tagging of attendees  
- **Privacy First:** Private-by-default profiles; content visible only to mutual friends  
- **User Discovery:** Search for friends, view profiles, and access recent searches  

---

## Tech Stack
- **Frontend:** SwiftUI, UIKit  
- **Backend:** Firebase Auth & Firestore  
- **Local Storage:** Core Data  
- **Navigation & UI:** Custom navigation coordinator, matched-geometry transitions
